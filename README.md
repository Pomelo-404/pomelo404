# pomelo404

Landing page de un estudio de desarrollo web, construida con Next.js, React y TypeScript para desplegarse en Vercel.

## Desarrollo local

```bash
pnpm install
pnpm dev
```

Abre `http://localhost:3000`.

## Validación

```bash
pnpm build
```

## Deploy en Vercel

Importa el repositorio en Vercel o ejecuta `pnpm dlx vercel`. El framework se detecta como Next.js. Configura `NEXT_PUBLIC_SITE_URL` con la URL final para los metadatos sociales.

## Continuidad

Consulta `PROJECT_GRAPH.md` antes de agregar proyectos reales, conectar el cotizador o cambiar la arquitectura.
