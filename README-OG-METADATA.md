# OG y metadata de pomelo404

## Instalación

1. Copia las tres imágenes PNG a `public/`.
2. Copia `pomelo404-pixel-iso.png` a `public/` si aún no existe.
3. Renombra `layout-professional.tsx` como `layout.tsx` y colócalo en `app/`.
4. Conserva `NEXT_PUBLIC_SITE_URL=https://pomelo404.vercel.app` en Vercel o sustitúyelo cuando conectes un dominio propio.
5. Publica y prueba la URL con LinkedIn Post Inspector, Facebook Sharing Debugger y una vista previa de X/Twitter.

## Imágenes

- `og-pomelo404-primary.png`: opción recomendada y configurada como principal.
- `og-pomelo404-neon.png`: alternativa para campañas o páginas oscuras.
- `og-pomelo404-editorial.png`: alternativa para portafolio, artículos o presentación del proceso.

Las plataformas sociales normalmente muestran solo la primera imagen de Open Graph. Las tres se mantienen en metadata para consumidores que aceptan galerías, pero Twitter utiliza únicamente la principal.

## Datos no incluidos

No se añadieron teléfono, perfiles sociales, dominio personalizado ni códigos de verificación porque todavía no están confirmados.
